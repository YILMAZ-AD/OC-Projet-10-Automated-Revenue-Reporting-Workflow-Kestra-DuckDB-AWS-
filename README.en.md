# Automated Revenue Reporting Workflow (Kestra-DuckDB-AWS)

## Context: The BottleNeck Problem
BottleNeck is a prestigious wine merchant that runs sales on two fronts:
1. **A physical store** (with an ERP inventory management tool).
2. **An online store** (the website).

**The problem?** Until now, cross-referencing online sales with physical stock was done 100% manually in Excel. It was a long process, repetitive at the end of every month, and prone to human error.

## The Solution: A Fully Automated Pipeline
I turned this manual process into a proper industrial data flow. The pipeline now triggers automatically every month and handles the entire job from start to finish, with zero human intervention.

### Architecture and Technologies Used
* **AWS S3:** Cloud hosting for secure storage of source files.
* **Kestra:** The orchestrator. It automatically schedules and drives every step of the flow.
* **Python & Pandas:** For cleaning the raw data.
* **DuckDB:** For running complex joins and analytical queries with optimal performance.

## How It Works (The Workflow)
1. **Extraction:** The pipeline automatically downloads the 3 source files directly from the AWS S3 bucket.
2. **Cleaning & Joining:** ERP and Web data are cleaned, standardized, then merged using a linking file.
3. **Analysis & Calculations:**
    * Calculating total Revenue and revenue by product.
    * Detecting anomalies and classifying wines (Premium vs Standard) using Z-score statistical calculation.
4. **Generating Deliverables:** The pipeline automatically creates the final reporting files.

## Repository Structure
* `bottleneck_sales_pipeline.yaml`: The full Kestra workflow source code.
* `project_presentation.pdf`: A simplified presentation of the project and technical choices.
* `architecture_diagram.png`: The visual diagram of the pipeline infrastructure.
* `outputs/`: The folder containing the deliverables automatically generated by the code:
    * `sales_report.xlsx`: The complete revenue reporting file.
    * `premium_wines.csv`: The automatic extraction of premium wines.
    * `standard_wines.csv`: The extraction of standard wines.
